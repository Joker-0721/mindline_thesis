\section{数值算例}

为验证本章所提混合离散格式在屈曲分析中的计算精度与免剪切自锁性能，本节对单轴均匀压缩载荷下方板在不同边界条件下的临界荷载系数与屈曲模态进行计算。

\subsection{方板算例}

如图\ref{CH4_plate_model} 所示，一方板求解域为 $\Omega = [-0.5, 0.5] \times [-0.5, 0.5]$，采用均匀节点离散，图中边界箭头表示各边的位移约束方向。四条边分别编号为 1（底边）、2（右边）、3（顶边）、4（左边），通过组合不同的边界约束条件（固支 C、简支 S、自由 F）构成六种典型工况：CCCC 为四边固支、SSSS 为四边简支、CSCS 与 SCSC 为固支与简支交替、FSCS 与 FSSS 为含一个自由边的工况。

屈曲临界荷载系数的验证基准基于 Kirchhoff 薄板理论。本算例厚跨比 $h/a=1/100$ 属于薄板范畴，Mindlin 理论的计算结果应收敛于 Kirchhoff 理论的解析解或经典参考解。

对于四边简支（SSSS）方板，采用 Navier 双三角级数法可获得精确闭合解。设板沿 $x$ 方向承受单轴均布压力 $N_x$，屈曲控制方程为：
\begin{equation}
D\nabla^4 w + N_x \frac{\partial^2 w}{\partial x^2} = 0,
\label{eq:buck-kirchhoff-control}
\end{equation}
其中弯曲刚度 $D = Eh^3/[12(1-\nu^2)]$。取满足四边简支边界条件（$w=0,\ M_n=0$）的试函数：
\begin{equation}
w(x,y) = \sum_{m=1}^{\infty}\sum_{n=1}^{\infty} A_{mn} \sin\frac{m\pi x}{a} \sin\frac{n\pi y}{b},
\label{eq:navier-mode-shape}
\end{equation}
式中，$A_{mn}$ 为待定幅值系数，$m$、$n$ 分别为 $x$ 与 $y$ 方向的半波数。将式\eqref{eq:navier-mode-shape}代入式\eqref{eq:buck-kirchhoff-control}，可得方板最低阶（$m=n=1$）屈曲临界荷载系数：
\begin{equation}
k_{\mathrm{SSSS}} = \frac{(m^2+n^2)^2}{m^2} = 4.000.
\label{eq:ssss-buckling-coefficient}
\end{equation}

对于四边固支（CCCC）、混合边界（CSCS、SCSC）及含自由边（FSCS、FSSS）的方板，边界条件无法用简单三角级数自动满足，不存在精确闭合解，需通过 Levy 单三角级数法或 Rayleigh-Ritz 能量法求解超越方程获得数值参考解。本文以 Timoshenko 与 Gere\cite{timoshenko1961} 及 Bui 等人\cite{bui2011} 的经典参考解为验证基准，各边界条件的最低阶屈曲系数汇总于表\ref{CH4_compare_table}。

从表\ref{CH4_compare_table}中可以看出，在六种边界条件下，MF、MF2 与 FEM 三变量混合元的临界荷载系数均与标准解吻合良好，相对误差基本在 0.4\% 以内（含自由边的 FSCS、FSSS 工况约 3\%）；标准 FEM 与 FEM 缩减积分的临界荷载系数整体偏低，其中 CCCC 工况偏低约 17.7\%、SSSS 工况偏低约 10.1\%，且 FEM 与 FEM 缩减积分两列的数值完全相同，表明二者同源、不能作为独立方法参与对比。

图\ref{CH4_convergence}为 CCCC 与 SSSS 两种典型工况下各方法的误差随单元尺寸变化的对比图。图中横坐标为 $\log_{10}(h)$，$h=1/(n-1)$ 为单元尺寸；纵坐标为 $\log_{10}(|K-K_{\mathrm{exact}}|/K_{\mathrm{exact}})$。误差值越往下，表示结果越精确。图中第二个 MF 变体标注为 MF1，与表\ref{CH4_compare_table} 中的 MF2 为同一格式。从图中可以看出，MF、MF1 与 FEM 三变量混合元的相对误差随网格加密始终保持在 $10^{-3}$ 量级的较低水平；标准 FEM 的相对误差在 CCCC 与 SSSS 工况下分别约为 17.7\% 与 10.1\%，且随网格加密未见下降，无法达到理论误差收敛率；FEM 缩减积分与标准 FEM 的收敛曲线完全重合，与表\ref{CH4_compare_table} 的观察一致。
